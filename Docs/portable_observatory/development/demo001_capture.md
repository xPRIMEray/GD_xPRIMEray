# Demo 001 deterministic capture

Demo 001 is a scripted visual demonstration of the production Observatory. Its thesis is: **Hide the rendering. Keep the physics. Observe what the light finds.**

Run from PowerShell:

```powershell
.\scripts\windows\capture_demo001.ps1
```

The launcher uses Godot MovieWriter with a fixed 30 FPS clock, a 1280x720 viewport, and native rendering. It writes an ignored review package under `output/demo001/`.

The choreography invokes the same production input paths as F, O, G, and Q. Demo presentation is enabled only after O has selected Optical-only World, suppressing development annotations while preserving core instrument status. E and H are exercised only to prove that they remain inert.

Formal transitions are state-driven: the harness waits for lifecycle `complete`, full processed-pixel coverage, sealed Probe View availability, and the expected film mode. Presentation holds use captured-frame counts. LIVE uses the normal physics-safe production render loop; the harness records observed film row cursors and does not substitute imagery.

The sealed Q segment is acquired after the LIVE cycle returns OFF. This is necessary because entering LIVE correctly invalidates the earlier formal seal. Outcome, Contact Events, and Transport Effort therefore share the second legitimate Complete generation.

`demo001_manifest.json` is **DEMONSTRATION provenance**, not measurement authority. The formal authority token and naturally available hashes are included only to qualify that the production acquisition stayed intact.
